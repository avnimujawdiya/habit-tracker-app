# 🧠 Habit Tracker App

A simple and minimal Habit Tracker web app to help you build consistency and track your daily habits efficiently.

---

## 🚀 Features

* ✅ Add new habits
* 📅 Track daily progress
* 📊 View habit logs
* 🔁 Persistent data using local storage
* 🎯 Clean and minimal UI

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
